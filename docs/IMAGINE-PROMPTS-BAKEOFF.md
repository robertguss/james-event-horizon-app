## Direction A — Comic ship computer (OUT)

### A1 — Home / hub

```
Create a tablet-landscape (16:9) home screen for a children’s educational space reading game, grades 3–5. Flat comic / graphic-novel look: bold ink outlines, cel-shaded colors, clean panels. A kid-friendly ship computer HUD with a star map, simple planet icons, and chunky outlined buttons labeled Missions, Hangar, Library, Academy. Bright, playful, high clarity. Original IP — not copying any franchise. No horror, no blood, no weapons, no logos, no watermarks. Short UI labels only.
```

### A2 — Mission / reading screen

```
Create a tablet-landscape (16:9) mission reading UI in flat comic style with bold ink outlines. Large cream reading panel with blank placeholder lines only (no real paragraphs). Circular telescope/scanner reticle as a comic prop. Bottom: big outlined multiple-choice buttons and short labels Scan and Hint. High contrast, calm focus, kid-friendly. Original IP. No horror, no logos, no watermarks, no dense fake text.
```

### A3 — Reward / unlock

```
Create a tablet-landscape (16:9) reward unlock screen in flat comic / ink-outline style. Friendly stylized black hole with a bright outlined accretion ring (awesome not scary). Cute rounded explorer ship with a sparkly trail. Banner text Unlocked or Level Up. Gold stars and XP icons. Wholesome celebration. Original IP. No horror, no gore, no logos, no watermarks. Minimal text only.
```
